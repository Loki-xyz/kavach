# NyayaAI (न्याय AI) — Indian Legal Intelligence Platform

**WashU Law International Vibe Coding Challenge 2026**

## Overview

NyayaAI transforms natural language legal problems into complete, ready-to-file legal packages. Built entirely using AI-assisted development (vibe coding), it demonstrates how lawyers can leverage AI to accelerate legal workflows.

## Features

1. **Natural Language Input** — Describe your legal problem in plain English
2. **Smart Issue Detection** — AI identifies the legal issue and applicable laws
3. **Document Generation** — Generates legal notices, complaints, and applications
4. **Case Law Research** — Finds relevant precedents and citations
5. **Deadline Calculator** — Calculates procedural deadlines and limitation periods
6. **Strategy Brief** — Provides litigation strategy overview

## Tech Stack

- **Frontend:** HTML + Tailwind CSS + Vanilla JS
- **Backend:** Python FastAPI
- **AI Engine:** OpenAI GPT-4o + Claude (via Codex/Nous Portal)
- **Legal Data:** Indian Kanoon API + Curated Indian Legal Database
- **Build Method:** 100% Vibe Coding (AI-assisted development)

## Demo Flow

1. User describes legal problem in natural language
2. AI detects issue and applicable Indian laws
3. System generates complete legal documents
4. Shows relevant case law and deadlines
5. Provides litigation strategy

## How to Run

```bash
# Backend
cd backend
pip install -r requirements.txt
uvicorn main:app --reload

# Frontend
# Open frontend/index.html in browser
```
